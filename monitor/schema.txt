# Every field a monitor record may contain. v2cc-monitor refuses to write a
# record with any other field, and tests/run.sh checks the same thing with
# its own parser. What each field means: docs/monitoring.md.
#
#   <kind> <path> <type> [<option>,...]
#
# kind "*" is the envelope every record has. A path names a value inside
# the record; "[]" is any element of an array. Types: string, number, bool.
# A line with options is allowed only while one of those options is on in
# the configuration. They are off by default.

*        v                              number
*        seq                            number
*        machine                        string
*        ts                             string
*        prev                           string
*        kind                           string
